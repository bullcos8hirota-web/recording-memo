# 要件定義書 — スマホでサクッと使えるAI録音メモアプリ

## 1. 背景・目的
外出先でも思い立ったらすぐ録音でき、その場でAIが要約して議事録として残せるアプリを、個人利用の範囲で無理なく維持できる形で作る。
サーバー運用やクラウド課金アカウントの管理負担を避けつつ、Gemini APIの従量課金だけで「本気の要約」を使えるようにする。

## 2. スコープ前提
- プラットフォーム: Webアプリ（PWA。スマホのホーム画面に追加してアプリのように使う）
- 処理方式:
  - 録音・保存・履歴管理・簡易要約はブラウザ内（IndexedDB）で完結
  - 高精度な文字起こし・議事録化は、利用者自身のGemini APIキーを使い、ブラウザから直接Google Gemini APIを呼び出す（オプトイン）
  - 自前サーバー・Cloud Run等の常時稼働インフラは持たない（課金アカウントの管理負担と運用の手間を避けるため）
- 主な利用シーン: 個人の打ち合わせ・メモ・ひとり言の録音を、その場で要約して残す
- 開発体制: 個人開発・個人利用、予算は最小限（Gemini APIの実費のみ許容）

この前提により、以下は明示的にスコープ外とする。
- 複数ユーザーでの共有・アカウント基盤
- 自前サーバーの常時運用（PC常時起動、Cloud Run常時デプロイ等）
- Google Driveへの自動アップロード（OAuth連携）。共有シート経由の手動保存で代替する
- 多言語対応、話者分離の高精度化、リアルタイム配信共有

## 3. ユーザー像・利用シーン
- 個人で、外出先・移動中・自宅などその場ですぐ録音し、後から要点だけ振り返りたい人
- Gemini APIの実費（月数十円〜数百円程度を想定）以外の固定費をかけたくない人
- 難しい設定（サーバー起動、OAuth設定）なしに、APIキーを1回入れるだけで使い始めたい人

## 4. 機能要件

### 4.1 録音
- マイクからの音声録音（開始／一時停止／再開／停止）
- 録音中の経過時間・簡易波形表示
- 録音データはブラウザ内（IndexedDB）に保存し、リロードしても消えない
- 録音停止と同時に自動保存され、Gemini APIキー設定済みなら自動で文字起こし・要約へ進む

### 4.2 文字起こし・要約（AI議事録）
- Gemini APIキーが未設定の場合: 端末内蔵のブラウザ音声認識（Web Speech API、対応ブラウザのみ）によるライブ文字起こしと、簡易な自動整理（キーワードベースの要点抽出）にとどめる
- Gemini APIキーが設定済みの場合: 録音音声をブラウザから直接Gemini APIに送信し、以下を1回のAPI呼び出しで生成する
  - タイトル・タグ
  - 全文文字起こし（セグメント単位、可能な範囲で話者推定）
  - 要約（概要／主な論点／決定事項／アクションアイテム）
- 生成結果は編集可能。うまく生成できない場合は「作り直す」で再実行できる

### 4.3 コスト管理
- Gemini APIキーはブラウザ（この端末）にのみ保存し、外部サーバーには送らない
- 月ごとの利用量（トークン数からの概算コスト）をこの端末側で記録し、自己申告の月次上限に達したら以降の自動AI呼び出しを止める（Google側の実際の請求を止める機能ではないため、Google Cloud Console側の予算アラート・割り当て設定も併用する）

### 4.4 履歴・管理
- 録音一覧（タイトル・日時・長さ・要約冒頭のプレビュー）
- タイトル編集、検索（タイトル・文字起こし・要約本文の全文検索）
- 個別削除
- Markdown / テキスト形式でのエクスポート、音声ファイルのダウンロード
- スマホの共有シート経由でGoogle Driveなど任意の保存先に送れる（自動連携はしない）

### 4.5 再生
- 録音の再生（シーク）
- 文字起こしの手動編集

## 5. 非機能要件

### 5.1 プライバシー・セキュリティ
- Gemini APIキー未設定時は、音声・テキストは一切外部に送信されない
- Gemini APIキー設定時は、その録音の音声データが利用者自身のAPIキーでGoogleのGemini APIに送信される（Payタイア＝課金プランでは学習利用されない設定を推奨）。この送信は明示的なオプトイン（APIキーを入れる操作）によってのみ有効になる
- APIキーはこの端末のlocalStorageに保存される。共有端末では、Google Cloud Console側でAPIキーの利用範囲・レート制限をかけることを推奨する

### 5.2 精度・品質
- 日本語の会話音声を主対象とする
- Gemini API利用時は商用クラウドLLMの精度、未設定時は簡易整理程度の精度、という前提をユーザーに明示する

### 5.3 パフォーマンス・コスト
- Gemini APIは録音1本ごとに1回のAPI呼び出し（音声を直接入力）で処理する
- 音声サイズは18MB未満を目安とする（それ以上は事前にエラー表示）
- 個人の軽い利用（1日数本・数十分程度）であれば、Gemini API実費は月数十円〜数百円程度を想定

### 5.4 対応環境
- 推奨: 最新版のスマホブラウザ（Chrome/Safari）、PCブラウザ
- PWAとしてホーム画面に追加してアプリのように起動できる

### 5.5 可用性・データ保全
- ブラウザのストレージ容量上限に近づいた場合に警告を表示（将来対応）
- 誤操作による削除に対する確認ダイアログ

## 6. 制約・リスク
- Gemini APIの料金体系・無料枠は変更され得るため、定期的に公式価格ページを確認する
- ブラウザストレージはユーザーがキャッシュクリアすると消失し得る（エクスポート・共有機能でバックアップ導線を用意する）
- 長時間録音（18MB超）はGemini APIへ渡せないため、チャンク分割は将来検討課題とする
- 自動更新される請求停止機能はないため、Google Cloud Console側の予算アラート・割り当て設定の併用を前提とする

## 7. MVP完了の定義（Done基準）
1. ブラウザでマイク録音ができ、IndexedDBに保存・一覧表示できる
2. Gemini APIキーを設定すると、録音から自動で文字起こし・要約（概要・論点・決定事項・アクションアイテム）が生成される
3. 履歴一覧から過去の録音を検索・再生・削除・共有（エクスポート）できる
4. Gemini APIキー未設定でも、録音・簡易整理・保存・共有は問題なく使える
5. サーバーやクラウドの常時稼働インフラなしに、スマホのブラウザだけで完結する
