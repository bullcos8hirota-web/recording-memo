# スマホ実機テスト手順

## 目的

スマホで録音し、Gemini APIで議事録化し、履歴に保存されるところまで確認する。サーバーやPCの常時起動は不要。

## 事前準備

1. Google AI Studio (https://aistudio.google.com/) でGemini APIキーを発行する。
2. Payタイア（従量課金）に切り替える場合は、Google Cloud Console側で予算アラート・割り当て（Quota）も設定しておく。

## 手順

1. アプリをビルドし、どこか（社内LAN、または無料の静的ホスティング）に配置してスマホからHTTPSで開けるようにする。

   ```bash
   cd app
   npm.cmd run build
   ```

   `dist/` フォルダの中身がそのままスマホから開けるURLに置ければよい（Cloudflare Pages、Firebase Hosting、GitHub Pagesなど、無料の静的ホスティングで十分）。

2. スマホでそのURLを開く。

3. 画面上部の「本気AI(Gemini)」の「設定」を開き、Gemini APIキーを入力して保存する。

4. 録音開始を押し、会話を数十秒録音して保存する。

5. しばらく待つと、履歴にAI議事録（要約・文字起こし）が保存される。

6. 履歴から「詳しく見る」で要約・文字起こし・再生を確認し、「共有・保存」からGoogle Driveなど任意のアプリに保存できることを確認する。

## 重要

- スマホのマイク録音は、ブラウザによってHTTPSが必要になる。HTTPのLAN URLでは録音できない場合がある。
- Gemini APIキーはこの端末のブラウザにだけ保存される。他人と共有する端末では、Google Cloud Console側でそのキーの利用範囲・レート制限をかけておくと安心。
- 音声は18MB未満を目安にする（それ以上は事前にエラーになる）。

## つながらない・録音できない時

- マイク権限がブロックされていないか確認する。
- HTTPS URLで開いているか確認する（HTTPだと録音できないブラウザがある）。
- Gemini APIキーが正しいか、月次利用上限に達していないか、AI設定の「今月の目安」表示で確認する。
