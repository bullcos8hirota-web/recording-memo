# スタジオ用タブレット映像同期システム（新版）

複数台のAndroidタブレットで、**それぞれ別々の動画**を **まったく同じタイミングで再生・ループ** させるためのシステムです。

旧マニュアル（各タブレットの内部時計＋手動offset調整）で「うまくいかない・ズレる・カクつく」問題を解決するために作り直しました。

## 仕組み（なぜズレないか）

- スタジオのWi-Fiに **司令塔PCを1台** 置き、これを **全タブレット共通の時計** にします。
- 各タブレットは自分のローカル動画を持ったまま、**再生位置だけ**を司令塔の時刻に合わせます。
  → 全端末が常に同じ位置になるので、完全に同時再生・同時ループします。
- ズレの補正は「シークで飛ばす」のではなく **再生速度をわずかに変えて滑らかに寄せる** ため、カクつきません。
- **手動のoffset調整は不要**。全タブレットで同じ `index.html` を使えます（違うのは各端末のローカル動画ファイルだけ）。

```
              ┌───────────────┐
              │  司令塔PC      │  ← 共通の時計（sync-server.js）
              │ 例:192.168.1.50│
              └───────┬───────┘
        Wi-Fi         │  「今 何秒か」だけを配信（動画は流さない）
     ┌────────┬───────┼───────┬────────┐
   ┌─┴─┐    ┌─┴─┐   ┌─┴─┐   ┌─┴─┐
   │Tab A│  │Tab B│  │Tab C│  │Tab D│  ← 各自ローカル動画を再生
   │動画A│  │動画B│  │動画C│  │動画D│    （長さは全部同じ）
   └────┘   └────┘   └────┘   └────┘
```

## セットアップ手順

### 1. 司令塔PCの準備（1回だけ）

> 🪟 **Windowsで、ダブルクリック起動の一番やさしい手順は [`WINDOWS-setup.md`](WINDOWS-setup.md) を見てください。**
> （司令塔PCは動画を流しません。時刻を配る“指揮者”役です）

1. PCに **Node.js** をインストールします（https://nodejs.org/ からLTS版）。
   - `npm install` は不要です。標準機能だけで動きます。
2. この `sync-player/server/sync-server.js` をPCに置きます。
3. PCをスタジオのWi-Fiにつなぎ、コマンド（ターミナル / PowerShell）で起動します。

   ```
   node sync-server.js
   ```

   動画の長さ（秒）を指定する場合：

   ```
   # Mac / Linux
   DURATION=1800 node sync-server.js

   # Windows (PowerShell)
   $env:DURATION=1800; node sync-server.js
   ```

4. 起動すると **タブレットに入力するアドレス** が表示されます（例 `http://192.168.1.50:8080`）。
   - このアドレスは後で使うのでメモしてください。
   - ブラウザで同じアドレスを開くと、稼働状況（現在のループ位置）を確認できます。
5. **本番中はこのPCを起動したままにしてください。**（PCは動画を配信しません。時刻を配るだけなので軽いです）

> 💡 PCのIPアドレスは固定しておくと安心です（ルーターのDHCP予約、またはPC側で固定IP設定）。IPが変わると各タブレットの設定を直す必要が出ます。

### 2. 各タブレットの動画とファイル準備

タブレットごとに、以下の2ファイルを用意します。

- **動画ファイル**：そのタブレットで流したい動画を `exercise.mp4` という名前にします。
  - タブレットごとに中身は違ってOK。ただし **長さは全タブレット共通** にしてください（同期の前提）。
- **システムファイル**：この `sync-player/tablet/index.html` を使います。
  - `index.html` の先頭にある `server` を、手順1でメモした司令塔PCのアドレスに書き換えます。

  ```js
  const CONFIG = {
    // 司令塔PCのアドレス。全タブレット共通。ここを書き換える。
    server: 'http://192.168.1.50:8080',
    video: 'exercise.mp4',
    duration: 0,   // 0のままでOK（司令塔PCの設定を自動取得）
  };
  ```

  > この `index.html` は **全タブレットで同じもの** を使えます。端末ごとに違うのは `exercise.mp4` の中身だけです。

### 3. タブレットへのファイル転送

パソコンとタブレットをUSBケーブルで接続し、以下のフォルダに2ファイルをコピーします。

**保存先フォルダ：** 内部共有ストレージ ＞ Android ＞ data ＞ de.ozerov.fully ＞ files

※必ず `files` フォルダの直下に入れてください（新しいフォルダは作らない）。

### 4. Fully Kiosk Browser の設定

1. 左メニュー ＞ **[Settings]** ＞ **[Advanced Web Settings]** を開く。
2. **[Play Web Media Without User Gesture]** に **チェックを入れる（ON）**。
   - これで自動再生が有効になります。
3. 左メニュー ＞ **[Settings]** ＞ **[Web Content Settings]** ＞ **[Start URL]** を開く。
4. **[PICK A FILE]** をタップ ＞ 右下の **[Select Storage]** を選択。
5. Android ＞ data ＞ de.ozerov.fully ＞ files と辿り、**index.html** を選択。
   - **旧版と違い、URLの後ろに `#offset=...` を書き足す必要はありません。** そのまま使います。

### 5. 動作確認

- 全タブレットで再生が始まり、同じ位置で動いていればOKです。
- 微調整の様子を確認したいときは、Start URL の末尾に `#debug=1` を付けると、
  画面左上に「サーバー接続状況・時刻差(offset)・ズレ(diff)・再生速度(rate)」が表示されます。
  （例：`.../index.html#debug=1`）確認できたら外してください。

## 運用上の注意点

- **司令塔PCは起動したままにする。** これが止まると新しい時計合わせができません（ただし各タブレットは直前の時計で動き続けます）。
- **カクつきが出た場合：** 長時間連続稼働でメモリが不足することがあります。本体の再起動、またはメニューの **[Clear Web Cache]** を実行してください。
- **同期の精度：** 起動直後にNTP方式で時計を合わせ、その後は30秒ごとに合わせ直し、0.4秒ごとに再生速度で微調整します。数十ミリ秒レベルで揃います。
- **動画の長さを変えたとき：** 司令塔PCの `DURATION` を新しい長さに変えて再起動すれば、全タブレットに反映されます。

## うまくいかないときは

| 症状 | 確認すること |
| :-- | :-- |
| 全タブレットがバラバラ／司令塔につながっていない | タブレットとPCが**同じWi-Fi**か。`index.html` の `server` のIP・ポートが合っているか。PCで `sync-server.js` が起動中か。 |
| `#debug=1` で「未接続(ローカル時計)」と出る | PCのファイアウォールがポート(既定8080)を塞いでいないか。ブラウザでタブレットから `http://（PCのIP）:8080/` が開けるか。 |
| 少しずつズレていく | 各タブレットの動画の**長さが本当に同じ**か。`DURATION` が実際の長さと一致しているか。 |
| 自動再生されない | Fully Kiosk の **[Play Web Media Without User Gesture]** がONか。 |

│   └── index.html                   … 各タブレットに入れるプレイヤー
