# 司令塔PC（Windows）かんたんセットアップ

> **司令塔PCは動画を流しません。** 「今が何秒か」を各タブレットに伝える“指揮者”の役です。
> 動画は今まで通り、各タブレットが自分の中の `exercise.mp4` を再生します。
> だからPCに動画ファイルを入れる必要も、PCに画面をつなぐ必要もありません。

## 用意するもの

- スタジオのWi-Fiにつながる Windows PC … 1台
- このフォルダの中の2ファイル
  - `server/sync-server.js`
  - `server/start-server-windows.bat`

---

## 手順

### ① Node.js をインストール（最初の1回だけ）

1. https://nodejs.org/ を開く。
2. 「**LTS**」と書かれた方のボタンをクリックしてダウンロード。
3. ダウンロードしたファイルを開き、**「次へ」を押していくだけ**でインストール完了。
   （難しい設定は不要です）

### ② ファイルをPCに置く

- `sync-server.js` と `start-server-windows.bat` の**2つを同じフォルダ**に置きます。
- 場所はどこでもOK（例：デスクトップに「映像同期」フォルダを作ってそこに入れる）。

### ③ 動画の長さを設定

1. `start-server-windows.bat` を右クリック →「編集」を選ぶ。
2. 次の行の数字を、**動画の長さ（秒）**に書き換える。
   - 例：30分00秒なら `1800`
   ```
   set DURATION=1800
   ```
3. 上書き保存して閉じる。

### ④ 起動する

- `start-server-windows.bat` を**ダブルクリック**するだけ。
- 黒い画面が開き、次のように表示されれば成功です：

  ```
  ===================================================
   スタジオ映像同期サーバー 起動しました
  ===================================================
   動画の長さ (duration): 1800 秒
   各タブレットに入力するアドレス:
     http://192.168.1.50:8080     ← この行をメモ！
  ---------------------------------------------------
  ```

> 💡 **初回だけ**「Windows セキュリティの警告（ファイアウォール）」が出ることがあります。
> その場合は **「プライベート ネットワーク」にチェックを入れて「アクセスを許可する」** を押してください。
> （これを許可しないと、タブレットからPCにつながりません）

### ⑤ 表示されたアドレスをタブレットに設定

- 上でメモした `http://192.168.1.50:8080` のような**アドレス**を、
  各タブレットの `index.html` の中の `server` に書き込みます（`sync-player/README.md` の手順2参照）。
- 全タブレットで**同じアドレス・同じ index.html**でOKです。

### ⑥ 本番中は起動したまま

- この黒い画面（ウィンドウ）は**閉じないでください**。閉じるとサーバーが止まります。
- 終わったら、ウィンドウを閉じるか `Ctrl + C` で停止します。

---

## 確認のコツ

- PCのブラウザ（EdgeやChrome）で、メモしたアドレス `http://192.168.1.50:8080` を開くと、
  **現在のループ位置がリアルタイムで動くダッシュボード**が見えます。動いていれば正常です。
- タブレット側の確認は、Start URL の末尾に `#debug=1` を付けると、画面左上に接続状況が出ます。

## 安定運用のためのおすすめ（11台以上の場合）

- **PCのIPアドレスを固定**しておくと安心です（Wi-Fiルーターの管理画面でこのPCのIPを予約、
  またはWindowsの「ネットワーク設定」で固定IPに設定）。IPが変わると各タブレットの設定を直す手間が出ます。
- **PCがスリープしないよう**に設定してください（設定 → システム → 電源 → スリープ「なし」）。
  スリープするとサーバーが止まります。
- タブレット台数が多いときは、Wi-Fiルーターがしっかりした機種だと安定します
  （それでも司令塔から流れるデータはごく小さいので、映像を配信するより遥かに軽いです）。

## よくある質問

**Q. PCに動画を入れるの？**
いいえ。動画は各タブレットの中にあるものを使います。PCは時刻を配るだけです。

**Q. PCに画面（モニター）は必要？**
起動して放置するだけなので、基本は不要です。ただし起動操作とアドレス確認のために一時的にはあると便利です。

**Q. PCの電源を切ったらどうなる？**
新しい時計合わせができなくなります。各タブレットは直前の時計でしばらく動き続けますが、
長時間で少しずつズレる可能性があるので、本番中はPCを起動したままにしてください。
